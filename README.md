# Kanban Board

A simple Kanban Board application built using HTML, CSS and JavaScript to manage and organize daily tasks.

## Features

- Add new tasks to the To Do column.
- Edit existing tasks.
- Delete tasks.
- Drag and drop tasks between different columns.
- Add tasks using the Enter key.

## Columns

- Backlog
- To Do
- In Progress
- Done

## Technologies Used

- HTML
- CSS
- JavaScript


## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
